# tekt.md — Site Look & Feel v2 ("Blueprint")

Issues: #33 (theme), #34 (Mermaid), #35 (cover art) · Iteration **I1 · Solid Ground + New Face** · Layer **04-interface**, with tokens owned by **00-arkitype**

## Why

tekt.md is generated *using the arkitype meta language* (xingh/arkitype README → "See Tekt.md"), but it doesn't look like arkitype. The arkitype assets (`.knowledge/assets/arkitype.cover.*.png`, `arkitype.master.png`, `folder.*.png`) share a clear visual language. The current site, a navy/gold gradient hero with a centered title, doesn't use any of it. v2 brings tekt into the same family while keeping one thread of tekt's own identity: the amber/gold, and the navy as the dark theme.

## What the arkitype imagery does (and we adopt)

| Arkitype trait | Where it shows | tekt.md v2 treatment |
| --- | --- | --- |
| Light "blueprint paper" with a faint square grid and corner registration marks | every asset | `body` has a 32px grid on `--ground`; documents sit on a white **sheet** |
| Thin blue/violet line art, flat, no glow | `arkitype.master.png` | 1px `--line` borders, no gradients or glows; one soft shadow, used only on the sheet and the install card |
| Condensed heavy wordmark (`ARKITYPE`) | covers | **Barlow Condensed 700** uppercase for the wordmark, hero titles, layer names |
| Monospace dot-folder labels, colored per area (`.knowledge/` violet, `.arkitype/` blue, `.manage/` amber, `.archive/` slate) | covers, folder panels | **IBM Plex Mono**. Each layer has a lane color, and layer cards are titled like folders: `03-software/` |
| Connector motif: ■ solid line → dashed line → ○ hollow circle | under every title | `.rule` under hero titles and under every `h2`, in the current layer's color |
| Cards joined by a line with hollow-circle joints | cover row of four panels | the home page's five layer cards, joined in 00 → 04 build order |
| Dated task cards with status (`2025.05.20 Implement API`) | `.manage/` panel | *future*: an "iteration board" page rendered from GitHub milestones (I6 stretch) |

## Tokens (SITE PROFILE → `_data/site.json`)

The template reads colors, fonts, layers and nav from `_data/site.json`, so nothing brand-specific is hardcoded in `layout.njk`. #39 lifts this same block into `00-arkitype.md` as the canonical `SITE PROFILE`.

```yaml
brand:
  light: { ground: "#F6F8FC", grid: "#E5EAF3", surface: "#FFFFFF", sunken: "#EEF2F8",
           ink: "#172033", muted: "#5A6579", line: "#CFD7E4", accent: "#6E56CF", link: "#2E6BF6" }
  dark:  { ground: "#0B1220", grid: "#141D30", surface: "#101A2C", sunken: "#0D1627",
           ink: "#E4E9F3", muted: "#94A1B8", line: "#24324C", accent: "#A495F2", link: "#7AA2FF" }
  fonts: { display: Barlow Condensed, body: IBM Plex Sans, mono: IBM Plex Mono }
layers:            # lane colors — light / dark
  "00 arkitype":       ["#6E56CF", "#A495F2"]   # violet  (arkitype .knowledge/.arkitype line art)
  "01 infrastructure": ["#56637A", "#9AA7BF"]   # slate   (the INFRASTRUCTURE base plate)
  "02 database":       ["#0E8A8C", "#3FC6C7"]   # teal    (enterprise-canvas Databases)
  "03 software":       ["#2E6BF6", "#7AA2FF"]   # blue    (.arkitype/ blue)
  "04 interface":      ["#B8740E", "#F0AE45"]   # amber   (.manage/ amber = tekt's heritage gold)
```

Neutrals lean cool, toward the blueprint blue, and aren't pure grey. The layer color shows up in a few places only: the eyebrow, the connector rules, list markers, the code-block edge, the active nav chip and the TOC marker. Body text stays ink.

## Theme

- **Light (default):** blueprint paper.
- **Dark:** tekt night navy (`#0B1220`), the same grid dimmed, lane colors lightened for contrast. Colors are redefined only as tokens under `prefers-color-scheme: dark`, and `data-theme="light|dark"` overrides the OS in either direction.

## Page anatomy

1. **Masthead:** `TEKT.md` wordmark (condensed + mono `.md` in violet), tagline, GitHub link.
2. **Nav:** sticky and translucent. Each layer item carries its mono code chip (`03`), outlined in the lane color and filled when active. Section dropdowns come from `site.nav`.
3. **Hero:** left-aligned, never centered. The home hero shows the tekt wordmark next to the **install commands** (with Copy buttons); the one-liner is the product. Layer pages show `Layer 03 of 04 · tekt.iris`, the layer name in display type, the connector rule and a one-line blurb.
4. **Layer cards (home only):** five folder-titled cards in build order, joined by hollow-circle connectors. They stack to a list under 1000px.
5. **Sheet:** the markdown content on a white sheet with a 46rem measure. Tables scroll inside their own box. Mermaid fences render as diagrams on a fine-grid panel, themed from the tokens (fixes #34).
6. **On-this-sheet rail:** a sticky TOC from the h2s at ≥1100px, marking the current section.
7. **Pager:** previous/next layer along 00 → 04. The layers really are a sequence (build order), so the order is information, not decoration.
8. **Title block footer:** engineering-drawing convention. PROJECT · SHEET `03 / 04` · LAYER · CATALOG `2026.07` · SOURCE (links to the .md file on GitHub) · credits line.
